Privacy

Nothing leaves this Mac.

Portkeep is a local tool. It reads ports, processes, and project folders on your machine so you can see and stop them. That data is not uploaded, sold, or synced.

What stays on this Mac

  • Listening ports, PIDs, command lines, and working directories
  • Docker container names you already have locally
  • Port reservations in ~/.portkeep
  • License and trial state in local preferences

What can go to the network

  • Software Update (optional, on by default). Check for Updates asks https://portkeep.sajidpalagiri.com/appcast.xml for a version number. If you install an update, the signed disk image is downloaded from the same site. No port list, process list, or folder path is included.
  • Localhost health probes (off unless you enable them). A GET to http://localhost:<port>/ on this Mac only.

There is no account, no analytics, no crash reporter, and no third-party SDK except Sparkle for updates. Turning off automatic update checks in Settings stops the periodic request. You can still check manually.
