Stop the leftover tree.

Portkeep lists every listening port on this Mac, groups it by project, and shows whether a human, Cursor, or Claude Code started it. Stop the whole process tree. Reserve a stable port per worktree. Agents get a CLI and MCP. Your ports never leave the machine.

Download for Mac macOS 14+ · signed & notarized · Sparkle updates

What it does

  • Who started this Cursor Agent, Claude Code, your terminal, or an orphan reparented to launchd.
  • Stop the tree Not just the pid on the port. The wrapper, the children, then SIGKILL if it hangs.
  • Stable ports portkeep alloc web gives the same port back in this worktree.
  • For agents CLI on your PATH and an MCP server. No guessing at EADDRINUSE.

Updates, like macOS

Settings → Check for Updates… If there is a newer build, Portkeep downloads it and asks you to install. It can also check once a day in the background. That check is the only network the app uses, besides optional localhost health probes you turn on.
